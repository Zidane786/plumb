# Upgrade to 1.0.0

## What's new

The first release of Plumb. In plain words, you can now:

- set Plumb up in any project, in the right folder, with your OK at every step: `/plumb:init`;
- make a design system for a new project, from a few questions and 2–3 directions: `/plumb:create`;
- pull the design system out of an app you already have: `/plumb:extract`;
- prototype a screen before it is built, choosing between 2–3 variants with every state in light and dark:
  `/plumb:prototype billing`;
- write a walkthrough of the prototype for a client demo or training, and send it as one offline page:
  `/plumb:tour client-demo`;
- check the UI against the system and fix or improve it with your OK: `/plumb:audit`, `/plumb:audit fix`,
  `/plumb:audit improve`;
- review one screen's UX in depth: `/plumb:ux booking`;
- change the design, or add iOS and Android later: `/plumb:update add iOS`;
- see how healthy the design system is: `/plumb:status`.

While an agent builds, three hooks keep every edit on the system and check the changed screens before it hands back.
The complete guide is `docs/USAGE.md` in the Plumb repository.

## Steps

No upgrade steps: this is the first version. A project set up with `/plumb:init` on 1.0.0 is already current.
